# Química em Órbita

Abra `index.html` em qualquer navegador moderno para jogar. Não requer instalação nem conexão com a internet.

O jogo inclui 50 casas, até quatro jogadores locais, perguntas de química sem repetição na mesma partida, pontuação, salvamento local, dado animado, eventos relâmpago, pipetas e teletransportes.
